04 Selected Projects
  1. 01

    SchemaLens

    Point it at a legacy PostgreSQL database and it becomes readable again. Searchable docs for every table and function, a read/write lineage map parsed straight from the PL/pgSQL, plain-English explanations that get cross-checked against static analysis so you can trust them, and an MCP server so AI assistants write correct SQL against your schema. Accuracy is scored against a hand-labeled benchmark in CI.

    Python · TypeScript · PostgreSQL · PL/pgSQL · MCP
    Live Code
  2. 02

    IntentTrace

    When an AI agent gets tricked into buying something, who pays? IntentTrace investigates. A pre-payment gate blocks suspicious carts before money moves, and an investigator replays the purchase without the suspicious text to decide whether it was legitimate, out of scope, tampered with, or manipulated by prompt injection. Decisions land in a signed, tamper-evident log. Scored on a 300-case synthetic benchmark, and upfront that this tests the pipeline, not real-world accuracy.

    Python · FastAPI · React · TypeScript · MCP · Docker
    Live Code
  3. 03

    HeatSink

    A screening tool that answers one question: if you cooled an AI data center with seawater, where would its heat do the least harm to the ocean? It maps coastal temperatures, models the thermal plume, and gives planners a plain-English read. Covered by unit and property-based tests. Built with a teammate.

    TypeScript · React · Vite · Vitest
    Live Video Code
  4. 04

    Cloud-Native Serverless App

    Production-style AWS infrastructure in 3,000+ lines of Terraform (VPCs, EC2 Auto Scaling, RDS Multi-AZ, ALB, Route53), plus an SNS to Lambda to DynamoDB verification pipeline and secure-by-default IAM, KMS, and Secrets Manager.

    Python · FastAPI · Terraform · AWS
    Infra App
  5. 05

    Dry Run

    Rehearse a product decision before it's real. Seven AI stakeholders (engineering, marketing, risk, a devil's advocate and more) pressure-test the call, then a decision lead writes a brief with the case against it and an assumptions register. Every claim is tagged as given, benchmark, or assumption, and you can ground the panel in your own CSV so it argues from real numbers instead of inventing them.

    Python · CrewAI · Streamlit · OpenAI · Docker
